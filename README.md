# KiyanKa 👘✨  
KiyanKa is a soulful mobile application for designing and orderinghandmade Moroccan dresses, blendingartisanal tradition with modern elegance.  

## ✨ About KiyanKa
Kiyan (كيان) means self, presence in Arabic.
Ka (化) represents transformation in Japanese.

Together, KiyanKa symbolizes a sanctuary for self-expression, heritage, and rebirth through timeless fashion.

## The app offers:

🧵 Custom dress creation (fabric, color, and pattern choices)

👗 Ready-made designs curated with Moroccan and contemporary influences

💬 Behind-the-scenes stories of the artisanal journey

📸 Social showcases from real clients

💎 A future jewelry line integration

## 📱 Features
Browse Collections:
Seasonal, bridal, henna, and ceremonial dresses beautifully curated.

### Custom Order:
Pick fabric, color, patterns, and request a bespoke dress.

### Meet the Artisan:
Personal stories and process glimpses from the creator (my mom 💛).

### Featured Dress of the Week:
Spotlighting a unique dress with its emotional backstory.

### Social Gallery:
See real clients wearing KiyanKa pieces.

## 🎨 Design Philosophy
Inspired by Moroccan patterns and Japanese minimalism

Soft sand backgrounds, Moroccan red accents, golden highlights

Feminine, daring, elegant

## 🛠️ Built With

## 🚀 Getting Started
Prerequisites
Xcode 15 or later

iOS 17 or later simulator or device

Swift 5.9

### Running Locally
bash

Copy code

git clone https://github.com/ImaneBouamama/KiyanKa

cd KiyanKa

open KiyanKa.xcodeproj

Press Cmd + R to build and run the app!
